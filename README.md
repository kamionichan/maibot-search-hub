## 它能做什么

**查资料**

- **组合多个搜索来源**：不填 key 也能搜；填上免费 key（百度千帆、Exa 等）中文和技术问题效果更好。中文问题先用中文来源；一家出错或被限流就换下一家；深度搜索同时查几家再合并。
- **读原文、再核对，不只扔链接**：普通和深度搜索会自动打开排名靠前的网页，摘出和问题相关的段落；读不到（404、要登录、打不开）就换下一条。然后核对每条结果是不是真的回答了问题、时间对不对、是不是官方说法：
  - 讲的是别的事、旧消息，会被标出来或略去；
  - “转会爆料”和“官方宣布”分开说，标题写“官方公告”、实际是个人账号发的，不当官方消息；
  - 几条结果说法互相矛盾时，麦麦会说清各方说法，不下定论；都没回答上时直说没查到。
- **问“最新”不拿旧消息凑数**：结果全是旧文章时，麦麦会说“这是旧消息，没查到最新的”。
- **能追问、能看原文**：查过的每条结果都记着编号。接着问“那篇文章里还说了什么”，麦麦会直接读那篇原文，而不是重新搜一遍。

**图片**

- **以图搜图**：发番剧截图问“这是哪部”，能找到番名、集数和时间点；还能认动漫角色、找插画出处和作者、搜相似图片和风景照的出处。内置 trace.moe、AnimeTrace、SauceNAO、Yandex、百度识图、Bing，可选接入 Google Lens。
- **找到同一张图时把图发出来**：以图搜图确认是同一张图时，把缩略图交给麦麦，麦麦可以直接发出来。
- **找图发图**：对方说“发一张 XX 的图”时，插件用图片搜索找几张、下载下来交给麦麦，麦麦看过后挑合适的发出去。

**不打扰聊天**

- **慢的搜索转到后台**：一时查不完的问题，麦麦先接着聊，查到后自己把结果发回对话。
- **本机直接访问网页时自动限速**：以图搜图直接访问 Yandex、百度、Bing、Google 时，每个网站同一时间只查一次、两次之间留间隔，避免被当成机器人拦截；到了限制会换别的引擎，都用不了时麦麦会说“过一会儿再试”。

## 快速开始

1. **安装**：在 MaiBot WebUI「插件市场」搜索“搜索中枢”安装（已收录到官方插件中心；刚上架时市场可能要过一阵才同步出来）。也可以从 [Releases](https://github.com/kamionichan/maibot-search-hub/releases) 下载 zip，在「插件管理」里上传。
2. **重启麦麦**。
3. **看一眼下面的「装好先看」**，尤其是网络环境和核查模型两条。
4. **试一下**：在群里 @麦麦 问一个需要查的问题，比如“Node.js 最新的 LTS 是哪个版本？”

不填 key 时默认使用：Keenable、Tavily（免 key 模式）、trace.moe、AnimeTrace、Yandex、百度识图、Bing。如果你在 MaiBot 里配置了联网服务，它也会作为来源之一。插件只依赖 MaiBot 自带的 httpx，通常不需要额外安装依赖。

## 装好先看

这几条会直接影响能不能用、好不好用，建议装完就检查一遍。

### 1. 网络环境决定哪些来源能用

插件的搜索来源大多是境外服务。**麦麦所在服务器能不能访问它们，决定了这些来源能不能用**——插件没法替你判断。

- 服务器在中国大陆：多数境外来源可能连不上或不稳定。建议至少申请**百度千帆**（中文效果好、国内可直连），并在「常用 → HTTP 代理」填一个能访问境外的代理。
- 服务器在境外：通常不用填代理；百度千帆、百度识图等国内服务反而可能慢一些。

每个来源大致属于哪一类、代理会不会经过它，见下面的「网络环境与代理」一节。来源一直失败时，发 `/search status` 看原因。

### 2. 结果核查要用不开深度思考的模型

普通和深度搜索会调用一次你在 MaiBot 里配置的模型来核对结果，默认用 `fast_model`（快速模型）任务，没配置时 MaiBot 自动改用 `utils`。

- **核查用的模型不要开深度思考**：思考会占满输出，核查变慢甚至为空（这时只用规则检查，标签会少很多）。
- **从 0.6.0 升级上来的**：旧配置里写着 `utils`，**升级后不会自动改**。如果你的 `utils` 开着深度思考，到「常用 → 结果核查」把“核查用的模型任务”改成 `fast_model`，并确认 MaiBot 里配了快速模型。
- 日志里出现“结果核查未完成，只用规则检查”，多半就是这个原因。

### 3. 搜索要花多少时间，取决于你的网络和模型

插件不保证固定的速度：搜索服务、网页本身、核查模型的快慢都取决于你的网络和服务商。插件能做的是不让慢的搜索卡住聊天：

- 快速搜索只用摘要；普通和深度搜索要读原文、调用核查模型，耗时明显更长。
- 搜索在「高级 → 等待与读原文」设定的时间（默认 4 秒）内没完成，就转到后台，麦麦先接着聊，查完再发回来。
- 每次搜索有总时限（默认 60 秒，以图搜图放宽到 2 倍），读原文、核查也各有时限，超时就用已拿到的结果。
- **找图发图例外**：图片要直接交给麦麦，所以不转后台，麦麦会等这次找图结束（插件内部时限约 18 秒）。

觉得太慢：可以把“普通搜索自动读取原文”改成 0，或关闭模型核查；或者换更快的核查模型、配代理。

### 4. 找图和以图搜图默认不过滤真人和成人内容

- **找图发图**：默认不过滤。要过滤，在「以图搜图 → 按关键词找图」打开“找图时过滤成人内容”（真人照片没有可靠的自动识别办法，这个开关管不到）。
- **以图搜图**：trace.moe、SauceNAO 标成成人向的结果默认过滤；打开“允许成人向结果”后保留并标注。其他引擎不提供这类标记。
- 图片会上传到哪些网站，见「隐私与数据外发」。

### 5. 推荐顺手改一项 MaiBot 设置

搜索类回答句子较多。MaiBot 分句发送时，句子太多会把整条回复换成“不知道”“懒得说”之类的随机回复。建议在 `bot_config.toml` 里加上：

```toml
[response_splitter]
enable_overflow_return_all = true   # 句子太多时保留完整回复
```

插件不会修改 MaiBot 的配置。

## 网络环境与代理

下表是**一般情况**，实际以你的服务器能不能访问为准（各地网络、运营商、服务商的封锁和限流都会变）。

| 类别 | 来源 | 访问的网站 |
|---|---|---|
| 国内服务，中国大陆通常能直连 | 百度千帆 AI 搜索、博查、阿里云百炼（千问）、百度识图、AnimeTrace | `qianfan.baidubce.com`、`api.bochaai.com`、`dashscope.aliyuncs.com`、`graph.baidu.com`、`api.animetrace.com` |
| 境外服务，中国大陆通常需要代理 | Exa、Tavily、Keenable、Brave、Serper、Firecrawl、LangSearch、Parallel、Linkup、Perplexity；trace.moe、SauceNAO、Yandex、Bing、SerpApi | `api.exa.ai`、`api.tavily.com`、`api.keenable.ai`、`yandex.com`、`www.bing.com`、`api.trace.moe`、`saucenao.com`、`serpapi.com` 等 |
| 你自己部署的 | SearXNG、camofox 浏览器（Google Lens） | 你填的地址；它们再去访问哪些网站，由它们自己的网络决定 |
| 跟随 MaiBot | MaiBot 联网服务、fetch-url 插件 | 按 MaiBot / 那个插件自己的网络设置 |
| 读原文、找图、核对候选图 | 插件自己下载网页和图片 | 搜索结果里的各个网站、图床、CDN |

**「常用 → HTTP 代理」会经过的：** 文字搜索的各个来源、以图搜图的各个引擎（含 SerpApi）、插件自己读网页原文、找图（SearXNG 图片搜索、Tavily、下载候选图）、核对候选图。

**不经过的：** camofox 浏览器（插件直接连你填的地址）、MaiBot 联网服务和 fetch-url 插件（按它们自己的设置）。

代理留空时直连，不读取系统的代理环境变量。填了代理时，网址的域名交给代理解析，代理需要是你信任的、并且自己会拦住内网地址。

**被网站拦截时的表现：** 来源报“鉴权失败”“限流”“要求验证”时，插件会让它冷却一段时间、换别的来源；以图搜图直接访问网页的引擎还有限速（见「高级 → 以图搜图限速」）。`/search status` 能看到每个来源的状态、冷却原因和今日用量。

## 配置页一览

WebUI → 插件 → 搜索中枢，配置分四个标签页：

| 标签页 | 里面有什么 |
|---|---|
| 常用 | 文字搜索开关、代理、优先来源；结果核查 |
| 搜索来源 | 免费来源（Keenable、Tavily、MaiBot 联网服务、SearXNG）和需要 Key 的来源（百度、Exa、博查等）。填了 Key 的排在前面，标签上显示已填几个；没填的折叠在后面 |
| 以图搜图 | 二次元识别、相似图片、可选的 Google Lens、按关键词找图 |
| 高级 | 与其他搜索工具共存、等待与读原文、读取原文、以图搜图限速、回复时附带资料、搜索记录、配置页（显示全部设置） |

不常用的设置平时收起；改过的照常显示。想看全部时在「高级 → 配置页」打开“显示全部设置”。

页面顶部有「运行状态」和「清空全部搜索记录」。

## 命令

| 命令 | 作用 | 谁能用 |
|---|---|---|
| `/search status` | 各来源状态、冷却、今日用量；以图搜图引擎的限速情况 | 所有人 |
| `/search jobs` | 本聊天最近的搜索和找图 | 所有人 |
| `/search trace J3` | 某次搜索用了哪些来源、各花了多久 | 所有人 |
| `/search cancel J3` | 取消进行中的搜索 | 所有人 |
| `/search clear` | 清除本聊天的搜索记录 | 操作员 |

## 和其他搜索插件一起用

| 对象 | 默认 | 说明 |
|---|---|---|
| MaiBot 自带的 `web_search` / `web_fetch` | 隐藏 | 本插件已经通过同一个联网服务使用它，再给模型看只会重复搜索 |
| 其他插件的搜索工具 | 观察 | 不干预，只把它们搜到的网址也记下来，之后可以追问 |

“隐藏”只是这一轮不让模型看到，不会停用其他插件，也不改 MaiBot 配置。可以在「高级 → 与其他搜索工具共存」里改成“观察”“隐藏”或“不处理”。

同时装了好几个综合搜索插件时，麦麦可能对同一个问题搜好几遍。建议只留一个综合搜索插件，专门领域的（比如 X/推特搜索）可以保留。

## 隐私与数据外发

**会发出去的：**
- 文字搜索：搜索词发给你启用的搜索来源，包括你自己填的 SearXNG。
- 读取网页原文：网址默认先交给 MaiBot 联网服务读取，其次交给 fetch-url 插件（装了的话），都不可用时才由插件自己下载。前两者会不会再把网址或内容交给它们自己的服务，取决于它们的实现；插件自己下载时只访问公网地址。
- 以图搜图：图片先去掉 EXIF 等元数据、重新压缩（最长边 1280 像素、不超过 1 MB；原图很大时也不会整张上传），再发给对应服务（trace.moe、AnimeTrace、SauceNAO、Yandex、百度识图、Bing；填了 SerpApi Key 还有 SerpApi/Google，填了 camofox 地址则经你的 camofox 浏览器发给 Google Lens）。这只去掉文件里的附加信息，画面本身不做处理。快速和普通档拿到确定结果就停；深度档会继续查别家，直到覆盖至少两类结果（例如“番剧场景”和“插画出处”）。
- 结果核查：普通和深度搜索时，搜索词、麦麦写的“对方想弄清什么”和读到的网页摘录，会交给你在 MaiBot 里配置的模型（默认 `fast_model`）判断；麦麦没写“对方想弄清什么”时，改为带上最近几条聊天（发言人只标“你/对方”，去掉 @昵称和 5–13 位长数字）。这不是完整的匿名化：聊天正文里直接写出的名字、地址等会原样交给这个模型，它可能和主聊天模型不是同一家。这些**不会发给搜索服务**。
- 按关键词找图：分几步，每一步的接收方不同——
  1. 搜索词发给 SearXNG（你填的地址）和 Tavily；**不上传聊天里的图片**。
  2. 插件下载候选图（原图失败时用缩略图），会访问这些图片所在的网站或 CDN。同一个网站同一时间只下一张，两次之间有间隔。
  3. 下载的图重新压缩后交给 MaiBot，作为工具结果里的图片；MaiBot 会把它放进麦麦的上下文，你配置的图像理解模型也会看到。
  找图有自己的开关（「以图搜图 → 按关键词找图」），关掉“启用以图搜图”不会关掉它。
- 核对候选图：以图搜图找到候选后，会下载候选的缩略图来核对是不是同一张图（会访问缩略图所在的网站或 CDN）。

**怎么关：**
- 不想外发文字：关闭「常用 → 允许文字搜索」。
- 不想让别的服务读网页：关闭「高级 → 读取网页原文」里的“优先用麦麦联网服务读取”“其次用 fetch-url 插件读取”；整个关掉“允许读取网页原文”就不读。
- 不想让模型核查结果：关闭「常用 → 结果核查 → 用模型核查搜索结果」（规则检查照常进行，不调模型）；只是不想带上聊天内容，关闭“麦麦没写搜索目的时，参考最近几条聊天”。
- 不想外发图片：关闭「以图搜图 → 启用以图搜图」；只关 Yandex、百度识图、Bing 也可以。不想下载候选图：关闭“下载候选图核对”。不想找图：关闭“按关键词找图”。
- camofox 地址会收到上传的图片和你填的 camofox Key：只填自己信任的服务，跨机器时优先用 HTTPS。camofox 的 `CAMOFOX_API_KEY` 只保护部分接口，想保护全部接口要设 `CAMOFOX_ACCESS_KEY`（以你部署的版本为准）。

**本地保存的：**
- 搜索结果的标题、摘要和网址，默认保留 30 天；调用记录保留 7 天（清理在加载和搜索时进行）。网页全文和图片只在内存里短暂缓存，不写入磁盘。
- 随时可以在配置页一键清空。正在进行的搜索不受影响，完成后照常发回。
- key 只存在插件配置里。插件会把已登记的 key 和网址里 `key=`、`token=` 一类的参数从**错误信息和日志**里遮掉（换 key 后旧 key 也会继续遮一段时间）。这是尽力而为：如果某个服务把 key 改头换面后回显，插件认不出来。
- 搜到的内容（标题、摘要、网页正文、网址）是公开的，插件原样保存和展示，不做遮挡：网页里本来就写着的“key”不是你的 key，改写反而会把正常网址改坏。

## 常见问题

**填了 key 但那个来源一直不工作？**
发 `/search status` 看它是不是在冷却、原因是什么。“鉴权失败”多半是 key 填错了，注意浏览器的自动填充可能把别的内容填进 key 框；“连接失败”“超时”多半是服务器访问不了这个网站，见「网络环境与代理」。改正后插件会立即解除冷却。

**以图搜图说“达到了使用限制”？**
本机直接访问网页的引擎（Yandex、百度识图、Bing、Google Lens 浏览器）有限速，到了限制会跳过；都跳过时就会这样说。过一会儿再试即可，`/search status` 能看到多久后可用。限速可以在「高级 → 以图搜图限速」调，但调得太松容易被网站拦截。

**麦麦不发图？**
发不发由麦麦的模型决定，插件只负责把图交给它。另外：
- 找图发图要对方明确说“发一张 XX 的图”这类话，模型才会去找；
- 以图搜图只有确认找到**同一张图**时才附缩略图，照片找人时不附，后台送回的结果暂时不附图；
- 成人向结果只在“允许成人向结果”打开时附。

**日志里有“结果核查未完成，只用规则检查”？**
核查模型超时或输出为空，见「装好先看」第 2 条。

**麦麦回复被换成“不知道”“懒得说”？**
这是 MaiBot 分句发送的设置导致的，见「装好先看」第 5 条。

**怎么升级？**
在 WebUI「插件市场」打开本插件，有新版本时点“更新”即可。更新会保留配置和搜索记录，不需要重启麦麦；用 zip 装的也能这样更新。
不能用上传 zip 的方式覆盖升级（会提示“已安装”）。确实要手动升级的话，先停麦麦，把新版文件解压覆盖到插件目录（配置文件 `config.toml` 不在安装包里，不会被覆盖），再启动。手动升级过以后，最好一直手动升级，或者改回市场更新后不再手动覆盖。
升级后看一眼 [CHANGELOG.md](CHANGELOG.md) 里这一版的“升级注意”。

**麦麦明明搜到了却没用上？**
是否参考搜索结果由麦麦的模型决定。插件会把刚搜到的资料附给回复模型，要求先说资料里的答案、只说资料里写明的内容；人设很强时模型仍可能按人设随口回答，换用理解力更强的回复模型通常会更好。

**麦麦闲聊时也去搜索？**
是否搜索由麦麦的规划模型决定。插件在工具说明里要求“闲聊、开玩笑、吐槽时不要搜”，但模型不一定照做。搜得太频繁的话，可以在配置页降低付费来源的每日上限。

**问歌词、台词时不给原文？**
资料里有原文时，插件允许回复模型直接引用。给不给最终由模型决定，有的模型会出于版权考虑只给链接。

**核查会额外花钱吗？**
普通和深度搜索每次多调用一次你配置的模型（默认 `fast_model` 任务），输入约一两千字。

## 作者的测试环境

插件是在下面的环境里开发和实测的。**你的模型、网络、MaiBot 版本不同时，表现可能不同**——尤其是“麦麦会不会主动搜索、会不会用上搜索结果、会不会发图”，主要由模型决定。

| 项目 | 正式实例 | 测试实例 |
|---|---|---|
| MaiBot | 1.4.3（多 Bot 布局） | 1.3.18、1.4.3 |
| 规划模型（planner） | gemini-3.8-flash | gpt-6.1-sol |
| 回复模型（replyer） | gemini-3.8-flash | deepseek-v4.1-flash |
| 核查用的模型（fast_model） | deepseek-v4.1-flash，关闭深度思考 | 未配置，退回 `utils`：deepseek-v4.1-flash，开着深度思考（核查经常超时，正好用来测“只用规则检查”这条路） |
| 识图模型（vlm） | gemini-3.8-flash | gpt-6.1-sol |
| 网络 | 能直接访问境外服务（插件里没有填代理） | 同上 |
| 已用的来源 | 百度千帆、Exa、博查、Keenable、Tavily、Firecrawl、LangSearch、Serper、SearXNG（自建）；以图搜图用 SauceNAO 及内置引擎 | 同上；Google Lens 只在 camofox 上做过单独测试，SerpApi 没有实测 |

单元测试在断网环境下运行（测试里禁止实际联网），覆盖来源适配、读原文、核查、以图搜图、限速和配置页。
