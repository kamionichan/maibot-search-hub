<h1 align="center">MaiBot 搜索中枢</h1>

<p align="center">让麦麦会查资料、会以图搜图：组合多个搜索来源，发张截图就能认出番剧和出处；慢的搜索转到后台不耽误聊天，查到的内容带出处自然接回对话。</p>

## 它能做什么

- **群友问最新消息，麦麦带着出处回答**
  “英特尔今天为什么暴跌？” → 麦麦几秒内查到“第四季度指引不及预期、以色列工厂停产”，回答时说明来源。
- **慢的搜索不耽误聊天**
  一时查不完的问题自动转到后台，麦麦先接着聊，查到后自己把结果发回群里。
- **先读原文、再核对，不只扔链接**
  普通和深度搜索会自动读排名靠前的原文，再核对每条结果是不是真的回答了问题、时间对不对。比如问“EDG 最近是不是要分裂”，
  讲旧比赛的结果会被略去，“转会爆料”和“官方宣布”会分开说；都没回答上时，麦麦会直说没查到可靠答案。
- **能追问、能看原文**
  查过的每条结果都记着。接着问“那篇文章里还说了什么”，麦麦会去读原文，而不是重新搜一遍。
- **以图搜图**
  发番剧截图问“这是哪部”，能找到番名、集数和时间点；还能认动漫角色、找插画出处、搜相似图片和风景照。
- **不填任何 key 也能用**
  装好就能搜。想要更好的中文效果，再申请几个免费 key 填上即可。

## 快速开始

1. **安装**：在 MaiBot WebUI「插件市场」搜索“搜索中枢”安装（已收录到官方插件中心；刚上架时市场可能要过一阵才同步出来）。也可以从 [Releases](https://github.com/kamionichan/maibot-search-hub/releases) 下载 zip，在「插件管理」里上传。
2. **重启麦麦**。
3. **试一下**：在群里 @麦麦 问一个需要查的问题，比如“Node.js 最新的 LTS 是哪个版本？”

不填 key 时默认使用：Keenable、Tavily（免 key 模式）、trace.moe、AnimeTrace、Yandex、Bing。如果你在 MaiBot 里配置了联网服务，它也会作为来源之一。插件只依赖 MaiBot 自带的 httpx，通常不需要额外安装依赖。

### 推荐顺手改一项 MaiBot 设置

搜索类回答句子较多。MaiBot 分句发送时，句子太多会把整条回复换成“不知道”“懒得说”之类的随机回复。建议在 `bot_config.toml` 里加上：

```toml
[response_splitter]
enable_overflow_return_all = true   # 句子太多时保留完整回复
```

插件不会修改 MaiBot 的配置。

## 配置页一览

WebUI → 插件 → 搜索中枢，配置分五个标签页：

| 标签页 | 里面有什么 |
|---|---|
| 常用 | 文字搜索开关、代理、优先来源、缓存；与其他搜索工具共存 |
| 免费来源 | Keenable、Tavily、MaiBot 联网服务、SearXNG |
| 需要 Key 的来源 | 百度、Exa、博查等。标签上会显示已填几个；没填的默认折叠 |
| 以图搜图 | 二次元识别、相似图片、可选的以图搜图容器 |
| 高级 | 等待与并发、读取原文、结果核查、回复时附带资料、搜索记录 |

页面顶部有「运行状态」和「清空全部搜索记录」。

## 命令

| 命令 | 作用 | 谁能用 |
|---|---|---|
| `/search status` | 各来源状态、冷却、今日用量 | 所有人 |
| `/search jobs` | 本聊天最近的搜索 | 所有人 |
| `/search trace J3` | 某次搜索用了哪些来源、各花了多久 | 所有人 |
| `/search cancel J3` | 取消进行中的搜索 | 所有人 |
| `/search clear` | 清除本聊天的搜索记录 | 操作员 |

## 和其他搜索插件一起用

| 对象 | 默认 | 说明 |
|---|---|---|
| MaiBot 自带的 `web_search` / `web_fetch` | 隐藏 | 本插件已经通过同一个联网服务使用它，再给模型看只会重复搜索 |
| 其他插件的搜索工具 | 观察 | 不干预，只把它们搜到的网址也记下来，之后可以追问 |

“隐藏”只是这一轮不让模型看到，不会停用其他插件，也不改 MaiBot 配置。可以在「常用 → 与其他搜索工具共存」里改成“观察”“隐藏”或“不处理”。

同时装了好几个综合搜索插件时，麦麦可能对同一个问题搜好几遍。建议只留一个综合搜索插件，专门领域的（比如 X/推特搜索）可以保留。

## 隐私与数据外发

**会发出去的：**
- 文字搜索：搜索词发给你启用的搜索来源，包括你自己填的 SearXNG。
- 读取网页原文：网址默认先交给 MaiBot 联网服务读取，其次交给 fetch-url 插件（装了的话），都不可用时才由插件自己下载。前两者会不会再把网址或内容交给它们自己的服务，取决于它们的实现；插件自己下载时只访问公网地址。
- 以图搜图：图片先去掉 EXIF 等元数据、重新压缩，再发给对应服务（trace.moe、AnimeTrace、SauceNAO、Yandex、Bing；填了容器地址的话还有以图搜图容器）。这只去掉文件里的附加信息，画面本身不做处理。快速和普通档拿到确定结果就停；深度档会继续查别家，直到覆盖至少两类结果（例如“番剧场景”和“插画出处”）。
- 结果核查：普通和深度搜索时，搜索词、麦麦写的“对方想弄清什么”和读到的网页摘录，会交给你在 MaiBot 里配置的模型（默认 `utils` 任务）判断；麦麦没写“对方想弄清什么”时，改为带上最近几条聊天（发言人只标“你/对方”，去掉昵称和长数字）。这些**不会发给搜索服务**。
- 核对候选图：以图搜图找到候选后，会下载候选的缩略图来核对是不是同一张图（会访问缩略图所在的网站或 CDN）。

**怎么关：**
- 不想外发文字：关闭「常用 → 允许文字搜索」。
- 不想让别的服务读网页：关闭「高级 → 读取网页原文」里的“优先用麦麦联网服务读取”“其次用 fetch-url 插件读取”；整个关掉“允许读取网页原文”就不读。
- 不想让模型核查结果：关闭「高级 → 结果核查 → 用模型核查搜索结果」（规则检查照常进行，不调模型）；只是不想带上聊天内容，关闭“麦麦没写搜索目的时，参考最近几条聊天”。
- 不想外发图片：关闭「以图搜图 → 启用以图搜图」；只关 Yandex、Bing 也可以。不想下载候选图：关闭“下载候选图核对”。
- trace.moe 和 SauceNAO 的成人向结果默认过滤（按它们给出的标记）。打开「以图搜图 → 允许成人向结果」后，这些结果会保留并标注“成人向”。其他引擎（AnimeTrace、Yandex、Bing 等）不提供这类标记，插件无法过滤，也无法标注。
- 「代理」留空时直连，不读取系统的代理环境变量。填了代理时，网址的域名交给代理解析，代理需要是你信任的、并且自己会拦住内网地址。

**本地保存的：**
- 搜索结果的标题、摘要和网址，默认保留 30 天；调用记录保留 7 天（清理在加载和搜索时进行）。网页全文和图片只在内存里短暂缓存，不写入磁盘。
- 随时可以在配置页一键清空。正在进行的搜索不受影响，完成后照常发回。
- key 只存在插件配置里。插件会把已登记的 key 和网址里 `key=`、`token=` 一类的参数从错误信息、搜索结果和日志里遮掉（换 key 后旧 key 也会继续遮一段时间）。这是尽力而为：如果某个服务把 key 改头换面后回显，插件认不出来。

## 常见问题

**填了 key 但那个来源一直不工作？**
发 `/search status` 看它是不是在冷却、原因是什么。“鉴权失败”多半是 key 填错了，注意浏览器的自动填充可能把别的内容填进 key 框。改正后插件会立即解除冷却。

**麦麦回复被换成“不知道”“懒得说”？**
这是 MaiBot 分句发送的设置导致的，见上面「推荐顺手改一项 MaiBot 设置」。

**怎么升级？**
在 WebUI「插件市场」打开本插件，有新版本时点“更新”即可。更新会保留配置和搜索记录，不需要重启麦麦；用 zip 装的也能这样更新。
不能用上传 zip 的方式覆盖升级（会提示“已安装”）。确实要手动升级的话，先停麦麦，把新版文件解压覆盖到插件目录（配置文件 `config.toml` 不在安装包里，不会被覆盖），再启动。手动升级过以后，最好一直手动升级，或者改回市场更新后不再手动覆盖。

**麦麦明明搜到了却没用上？**
是否参考搜索结果由麦麦的模型决定。插件会把刚搜到的资料附给回复模型，要求先说资料里的答案、只说资料里写明的内容；人设很强时模型仍可能按人设随口回答，换用理解力更强的回复模型通常会更好。

**麦麦闲聊时也去搜索？**
是否搜索由麦麦的规划模型决定。插件在工具说明里要求“闲聊、开玩笑、吐槽时不要搜”，但模型不一定照做。搜得太频繁的话，可以在配置页降低付费来源的每日上限。

**问歌词、台词时不给原文？**
资料里有原文时，插件允许回复模型直接引用。给不给最终由模型决定，有的模型会出于版权考虑只给链接。

**插件会让麦麦变慢吗？**
快速搜索大多在 1–3 秒内完成。普通和深度搜索要读原文、再核查，一般需要 5–15 秒；超过 4 秒（可调；子代理另有设置）就转到后台，麦麦先接着聊，查完再把答案发回来，不会卡住聊天。想要快一点，可以在「高级」把“普通搜索自动读取原文”改成 0，或关闭模型核查。

**核查会额外花钱吗？**
普通和深度搜索每次多调用一次你配置的模型（默认 `utils` 任务），输入约一两千字。建议在「高级 → 结果核查」里填一个便宜、快的模型任务。以图搜图要先取图、清洗图片，这一步不算在等待时间里。
